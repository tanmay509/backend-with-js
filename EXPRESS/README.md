# Backend Development with JavaScript & TypeScript

> My journey of learning backend development, understanding how the web works behind the scenes, and building real-world applications.

This repository documents my journey of becoming a backend developer, starting with **JavaScript, Node.js, and Express.js**, and eventually transitioning to **TypeScript**.

Rather than just collecting tutorials, this repository serves as my personal learning journal, containing code implementations, experiments, notes, concepts, and projects developed along the way.

## 🎯 Goals

- Build a strong foundation in backend development.
- Understand how servers, APIs, databases, and authentication work.
- Learn to design and develop RESTful APIs.
- Write clean, maintainable, and scalable backend code.
- Gain practical experience by building projects.
- Transition from JavaScript to TypeScript.
- Understand backend architecture and industry-standard practices.

## 🧠 Learning Methodology

My approach to learning is practical and iterative:

1. **Watch:** Learn concepts through video tutorials and courses.
2. **Code Along:** Implement the concepts while following the tutorials.
3. **Experiment:** Modify the code and try things independently.
4. **Understand:** Refer to official documentation and additional resources.
5. **Build:** Apply the knowledge in practical projects.
6. **Document:** Keep useful code examples and learning notes here.
